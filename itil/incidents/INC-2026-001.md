# INC-2026-001: eTenders OCDS API delta fails with HTTP 500 after page 2

| Field | Value |
|---|---|
| Detected (SAST) / by | 2026-10-19 09:40 and again at 09:55, `thusa ingest` (etenders_ocds) |
| Priority | P4: no live service; bulk mirror loaded; delta incomplete |
| Category | Stale data (upstream) |
| Affected service / CIs | SVC-01 (pre-live); CI-031 etenders_ocds |
| Status | Mitigated (known error KE-001) |

## Impact
- `ocds-api.etenders.gov.za/api/OCDSReleases` answered pages 1–2 (`PageSize=100`, window 14 Sep–19 Oct 2026) and then returned HTTP 500 on page 3. That happened in both runs, after 5 attempts each with exponential backoff.
- `PageSize` above 100 always returns 500.
- Releases after the bulk file (Last-Modified 20 Sep 2026) are therefore only partly loaded: 200 of an unknown total.

## Mitigation / workaround
- The bulk compiled-release file from the OCP Data Registry loads in full: 35,309 releases.
- The run status is `partial` and the error is kept in `ops.ingest_run`.
- No workaround of access controls was attempted. The API isn't access-controlled; it fails.

- CSI-002 (report to OCPO) is still open. CSI-011: page by smaller date windows (1 day) to reduce deep paging.
