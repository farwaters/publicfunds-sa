# Thusa v0.2.0: release notes (DRAFT, internal)

**Date:** 19 Oct 2026 · **Change:** CHG-2026-003 (Normal-high) · **Branch:** `feat/review-app`, stacked on
`feat/mvp-pipeline` (v0.1.0, PR #1) · **Status:** awaiting review. Not published.

## What's new
- **Review app** (`uv run pf serve` or `scripts/review-app.sh start`; http://127.0.0.1:8765):
  - **Flag queue:** filter by detector, severity, status (incl. "open" and "evidence changed"), named-supplier and free
    text. HTMX live filtering; works without JavaScript.
  - **Flag detail:**
    - explanation, evidence links and the raw file behind each checksum (lineage page);
    - matched records: the award and register entry with match confidence for D3, supplier shares for D4,
      value classes for D5, totals for D1, UIF&W history for D8.
  - **Decisions:** confirm, reject (false positive), needs more info or escalate. A reason is mandatory; notes are
    optional and internal. **Four-eyes:** a flag that names a supplier needs two different reviewers to confirm it on
    the same evidence.
  - **Audit trail:** append-only and hash-chained. Each decision records the reviewer, the time in SAST, the
    previous and new status and the reason. Integrity shows on `/audit` and `/healthz`.
  - **Coverage browser:** heatmap by data type, province, municipality and year range. Entity drill-down shows
    totals, UIF&W, audit outcomes and awards, with raw-file lineage links.
  - **Export** of reviewed flags as CSV or JSON. The JSON API (`/api/flags…`) uses bearer tokens.
- **`pf` CLI for bots and scripts:** `pf review list|show|decide|history|verify|export`, with JSON output and
  meaningful exit codes. Admin commands: `pf reviewer add|list|token|disable|reset-password`. Skill draft:
  `docs/bot/review-skill.md`.
- **Confirmed-only public snapshot:** `dist/public/` holds `index.html`, `flags.json`, `flags.csv` and
  `coverage.json`. Policy is set in `config/publication.yaml` (default `exclude`). The internal dashboard
  `dist/site` is labelled INTERNAL.
- **Data fix (KE-011):** province codes are normalised (KZ → KZN, LIM → LP), with a new DQ check (now 50 checks).

## Distribution (ADR-0009)
Thusa is a Grok Bot app. **Import the PublicFunds Bot template via its Grok Bot link `<TEMPLATE_LINK>`.**
- The bot chat is the primary UI. The localhost review web app is a secondary tool that the bot opens in its own
  box browser.
- Public web hosting is not an MVP requirement (D-03 and D-14 superseded).

## Security
- Localhost bind by default. Sign-in is required for every page except `/login` and `/healthz`.
- scrypt password hashes; hashed tokens and sessions; CSRF tokens.
- Strict CSP with no inline script; security headers; host allow-list; login rate limiting; a request size cap;
  CSV formula-injection protection.
- See CHG-2026-003 for the full list.

## Known gaps
