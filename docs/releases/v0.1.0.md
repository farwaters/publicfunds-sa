# Thusa v0.1.0: release notes (DRAFT, internal)

**Date:** 19 Oct 2026 · **Change:** CHG-2026-002 · **Branch:** `feat/mvp-pipeline` · **Status:** awaiting review. Not published.

## What's new
- **Ingestion** with retries and backoff. The raw store is idempotent: dated files, sha256 sidecars and an append-only manifest.
  - Municipal Finance API: income & expenditure v2, UIF&W, audit opinions, municipalities, demarcation changes.
  - eTenders OCDS: OCP bulk file plus API delta.
  - National Treasury Restricted Supplier & Tender Defaulter report (PDF).
  - Vulekamali budget-vs-actual CSV.
  - PPD manual-drop loader.
- **Layers:** raw → staging → curated → marts in DuckDB.
  - Money in integer cents. Blank means unknown and is never zero; a zero placeholder in eTenders becomes unknown.
  - Lineage on every curated row: `source_id`, `source_file`, `source_sha256`, `fetched_at_utc`, `source_locator`.
- **Coverage model (headline):** municipality × financial year × data type → present / partial / missing / n.a., computed only from loaded rows.
- **Detectors (all unreviewed indicators):**
  - D1 overspend vs budget (municipal cash opex; national votes).
  - D3 restricted supplier awarded (name match, pending human review).
  - D4 supplier concentration (pending human review).
  - D5 award-value gaps.
  - D8 irregular-expenditure trend.
- **Local dashboard:** coverage heatmaps, top flags with evidence links, and a drill-down page for each of the 257 municipalities.
- **Tests:** 99 pytest tests. There's also a 49-check DQ gate that makes `thusa run` exit 2 on failure.
