# PublicFunds SA v0.4.0: release notes (DRAFT)

**Date:** 19 Oct 2026 · **Change:** CHG-2026-008 (Normal) · **Branch:** `feat/improvements-2026-10` · **Status:**
awaiting review. The site goes live from `main` after the merge.

## What's new
- **"What's new" page** (`#/changes`) and a **JSON Feed** of new public data (`public-data/v1/feed.json`).
  - Both come from a new `changes.json`. It gets an entry only when the published data actually changes: count changes,
    coverage change and the files changed.
- **"Known unknowns" by province** (`#/unknowns`): how much of each data type is fully published, partly published
  or missing for each province's municipalities, and the most common reason for the gaps.
- **"Report an error"** on every page. It opens a GitHub issue form prefilled with the page address. The form asks for
  no personal data, and it points to the official anti-corruption hotline (0800 701 701) for corruption reports.
- **Social share cards:** links shared on WhatsApp, X, LinkedIn or Facebook show a title, a description and a card
  image.
- **Accessibility and speed:**
  - WCAG contrast fixes and keyboard-focusable scrolling tables. axe-core reports 0 violations on all pages.
  - Fixed a layout shift.
  - Lighthouse mobile went from 77/96/100/100 to 100/100/100/100 (performance/accessibility/best practices/SEO,
    measured locally).
- **Roadmap:** a scored improvement backlog of 25 items (`docs/roadmap/improvements-2026-10.md`), also entered as
  CSI-026 to CSI-050.

## Unchanged
- The data sources.
- The flags policy: confirmed flags only, with 0 confirmed so far.
- `scripts/publish-public-data.sh`, and the nightly routine that runs it.
